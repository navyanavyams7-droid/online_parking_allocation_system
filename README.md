# Online Parking Allocation System

## Project Description
The Online Parking Allocation System is a web-based application developed using React.js to simplify and manage vehicle parking allocation. It allows users to view available parking slots, register vehicles, and manage parking bookings.

The system uses the Queue Data Structure (FIFO – First In, First Out) to ensure fair and systematic allocation of parking spaces.

## Technologies Used
- Frontend: React.js, HTML, CSS, JavaScript
- Version Control: Git and GitHub

## Features
- View available parking slots
- Vehicle registration
- Parking slot allocation
- Queue-based parking management
- User-friendly interface

## How to Run the Project

1. Clone the repository.
2. Install dependencies:
   `npm install`
3. Start the application:
   `npm start`

The application runs at http://localhost:3000.
